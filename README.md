# Astrally

Документация учебного ИИ-проекта Astrally, созданная в подходе Docs as Code.

Astrally — веб-сервис мистических консультаций с большой языковой моделью, раскладами Таро и добровольной персонализацией.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m mkdocs serve
```

После запуска документация доступна по адресу `http://127.0.0.1:8000`.
