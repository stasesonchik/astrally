# API Astrally

API предоставляет доступ к функциям мистического ИИ-сервиса Astrally. Через него клиентское приложение может создавать диалоги, отправлять вопросы языковой модели и выполнять расклады Таро.

## Основные операции

- `POST /conversations` — создать мистический диалог и выбрать стиль общения.
- `POST /conversations/{conversationId}/messages` — отправить вопрос и получить ответ языковой модели.
- `POST /tarot-readings` — создать расклад Таро на выбранную тему.
- `GET /tarot-readings/{readingId}` — получить ранее созданный расклад.

## Спецификация

Полное формальное описание находится в файле [`openapi.yaml`](openapi.yaml). Спецификация использует OpenAPI 3.0.3 и содержит параметры, тела запросов, успешные ответы, ошибки и переиспользуемые схемы данных.

Адрес сервера в спецификации является условным. Для этой практической работы реальный backend и отправка HTTP-запросов не требуются.

## Персональный контекст

Параметр `usePersonalContext` разрешает учитывать профиль и историю пользователя внутри Astrally. Он не предоставляет доступ к истории браузера, cookies или данным сторонних сайтов. Расширенная персонализация через браузерное расширение рассматривается как отдельный будущий модуль.

## Ограничения

Ответы языковой модели и трактовки карт предназначены для развлечения и саморефлексии. Они не являются достоверными предсказаниями или профессиональными рекомендациями.
